# Parameters:
#   rails         : usable rails after the shared resolver (active, provider enabled, provider verified).
#                   zero = no usable rail (Coming soon, route 503 no_active_rail); one = exactly one (merchant of record named,

#   provider      : provider of the single usable rail (paddle or creem). Only read when rails = one.
#   price         : products.price_usd (set = a numeric price; null = not for sale).
#   checkout_mode : products.checkout_mode (live = sold; gated, sandbox and paddle = not sold on the buy form). The DB CHECK
#                   constraint allows exactly these four values (migration 20261007000000_commercial_heritage.sql).

#   gated, sandbox or paddle, any rails, any price -> not purchasable, no merchant of record
#   live, price null, any rails        -> not purchasable ("Coming soon"), no merchant of record
#   live, price set, rails zero        -> not purchasable ("Coming soon"), no merchant of record
#   live, price set, rails one         -> purchasable, merchant of record = the single rail's provider
#   live, price set, rails two         -> purchasable (POST fallback), no merchant of record
