# The seed file pins the one-rail Creem live row (the merchant-of-record case for a non-Paddle provider), which pairwise alone does not force.
#
# Parameters:
#   rails          : usable rails after the shared resolver (active, provider enabled, provider verified).
#                    zero = no usable rail (Coming soon, route 503 Service Unavailable no_active_rail); one = exactly one (merchant of record named,
#                    overlay eligible); two = more than one (POST fallback, no merchant of record, no overlay).
#   provider       : provider of the single usable rail (paddle or creem). Only read when rails = one.
#   price          : products.price_usd (set = a numeric price; null = not for sale).
#   checkout_mode  : products.checkout_mode (live = sold; sandbox = sold only when sandboxAllowed is true; gated, paddle and null = not sold on the buy form).
#                    The column is nullable: the migration's CHECK (checkout_mode in (...)) passes on NULL (migration 20261007000000_commercial_heritage.sql),
#                    so null is a database-allowed state and is modelled.
#   sandboxAllowed : boolean gate from sandboxAllowed() (non-production runtime AND payments.sandbox_checkout_enabled === true).
#
# Expected outcome (oracle in checkout_rails_resolver.pairwise.test.ts, written from the specification):
#   gated, paddle or null, any rails, any price, any sandboxAllowed           -> not purchasable, no merchant of record
#   sandbox with sandboxAllowed = false, any rails, any price                -> not purchasable, no merchant of record
#   (live OR (sandbox with sandboxAllowed = true)), price null, any rails    -> not purchasable ("Coming soon"), no merchant of record
#   (live OR (sandbox with sandboxAllowed = true)), price set, rails zero    -> not purchasable ("Coming soon"), no merchant of record
#   (live OR (sandbox with sandboxAllowed = true)), price set, rails one     -> purchasable, merchant of record = the single rail's provider
#   (live OR (sandbox with sandboxAllowed = true)), price set, rails two     -> purchasable (POST fallback), no merchant of record
